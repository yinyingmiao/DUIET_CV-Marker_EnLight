This is a folder with all the codes written and used during the group project part of the elective DUIET. 
Used example codes from Rong-Hao Liang, Olaf Adan, and online references. 
All the codes were integrated by Yinying Miao. 
Finalised January 22nd, 2024. 
Updated March 9th, 2026.

OfficeSphere_CVMarker_Input.pde: The Processing file for the final realization, with detecting CV markers and sending the data to Arduino. 
Output_DemoCode: Arduino code for receiving data from Processing and adapting changes based on the data. 

Output_DemoCode.ino: Arduino code integrated (partially) based on the results of the user studies. Used for the final presentation demo. 
Output_TestCode.ino: Arduino code used for the user studies. With the original concept idea.
